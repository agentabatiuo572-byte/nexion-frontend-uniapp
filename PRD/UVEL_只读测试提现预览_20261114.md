# 只读测试提现预览

经用户确认，新 TEST「提现方式」页面提供明确的「测试提现（不会出款）」入口，使用现有底部弹层，不新增路由。仅后台提供有效测试预览元数据时显示；元数据关闭/404 时隐藏，生产默认不显示。原 USDT 与银行入口、布局、权限、真实通道能力及业务流程保持。

弹层说明只读、不扣余额、不创建提现单、不会调用出款通道。显示 BEP20 网络、当前账户真实 USDT 余额、既有最低金额、固定网络费用、余额比例与业务日次数；不使用 UVT 抵扣。输入金额后仅 GET 查询参数校验，显示预览净额与余额不足等拒绝原因。参数通过也明确仍不可提交或出款，不以此表示真实提现资格，不提供提交按钮。

金额须为正数、最多六位小数；失败可重新校验，不显示为成功。修改金额、关闭弹层、离页、切账号/绑定或环境后，旧响应不能覆盖新状态；预览数据不写入钱包、提现尝试或缓存。使用既有 NxSheet 和 NxButton 的键盘及关闭能力。

仅元数据 404 按正常未开放隐藏入口；认证、服务或网络错误在预览区域显示「测试预览暂不可用」及重试，不影响原 USDT/银行入口。金额校验遇到 404 则关闭弹层并撤销入口，其他错误撤销已校验结果并说明未创建提现单。

预览响应数值只接受有限 JSON number；未知、空值、布尔值及字符串不转换为零。次数须为整数、每日限额须为正、余额比例在 (0,1]；仅金额、净额和未执行的校验结果按合同允许 null。

验收默认关闭隐藏、新 TEST 显式启用显示、余额 0 输入 50 显示余额不足、费用限额与后端一致、重新输入/重试/离页恢复正常，真实余额和提现单无变化。G3 固定七日价格为 0.001 USDT/UVT，零上涨概率、零波动、引擎暂停；实际配置及当前快照发布由操作员单独留存回执。
