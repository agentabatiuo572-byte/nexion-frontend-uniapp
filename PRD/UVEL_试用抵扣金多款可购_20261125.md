# 试用抵扣金可购买多款设备

权威：正式后端 `GET /api/trial/purchase-options`、`GET /api/trial/state`、`POST /api/trial/convert` 与外部付款接口（后端 B90 已交付，接口契约见 uvel-docs 后端接口说明 PRD-B90-trial-purchase-options）。商品清单、金额、确认版本、能否购买都由接口决定；客户端只显示服务端报价并回传确认版本。界面写法见 design-system 04「试用详情与试用抵扣购买」与 03「单选行」。

#### [FEAT-TRIAL06] 用试用抵扣金任选一款设备

**① 用户故事**：作为正在试用或在可抵扣期的用户，我想用试用抵扣金从运营给出的几款设备里任选一款买下，以便买到最合适的设备，而不只能买正在试用的那台。

**② 验收(GWT)+异常路径**
- Given 后端支持可购设备接口、清单里除本人试用设备（A）外还有其他设备（B） When 打开试用详情 Then 头部下出现选择区：标题「专享限时折扣设备」，说明「任选一款，价格已抵扣 · 新设备接替试用机位」；A 在第一行带「本次试用」，其余按售价从低到高；每行显示设备图、名称、预估每日收益、抵后应付与划线售价；列表下一句「其他设备仅支持余额支付」。
- Given 选择区 When 进入 Then 默认选 A；A 不可买时选第一款可买的；从商城某款的入口进来时选那一款。When 换选 Then 票据与底部按钮「抵扣购机 · 应付」同步为该款的服务端报价，票据标题写出设备名。
- Given 清单只有 A When 打开 Then 不出现选择区，购买流程不变。Given 可购设备接口返回 404（后端未支持） When 打开试用详情、结算、商城 Then 按单设备流程只买 A，不报错，商城不出现标签和入口。这两种情况下，下列已定的文案与版面改动同样生效：底部按钮「抵扣购机 · 应付」、头部「购机时可抵扣」与 UVT「购后到账」、票据「试用抵扣金」行名不带括号金额与「可提现金额以钱包为准」、试用结算不设「优惠」一组（含 A 的旧流程）。
- Given 选 B 并点「抵扣购机」 When 进入结算 Then 结算带试用标记与该款编号；只能用余额，确认后直接输入支付密码；数量固定 1 台（Cloud Share 为 1 份）；不可用代金券、置换；折扣只在「核对订单」里列一次；托盘写「本单使用试用抵扣金，购买后试用结束」。选 A 时三种付款方式照旧。
- Given 余额转购成交 When 回执到达 Then 重新读取试用状态后进入购买结果；订单、结果页、设备页、赚取页都显示所买设备；试用结束，原试用机位换成所买设备，机位数不变。
- Given 商城 When 在可用抵扣金购买的时间内浏览 Then 清单里当前可买的 B 在商品卡显示「可用试用抵扣金」；B 的商品详情在名称和标语下有「用试用抵扣金购买」入口（带抵后价），进入试用详情并选中这款；底部托盘按钮上方写「立即购买按原价，不使用试用抵扣金」，「立即购买」仍是原价普通购买、不结束试用。A 和从活动、代金券入口打开的详情不显示这些。
- 异常1：Given 清单首次读取中或读取失败 When 在试用详情 Then 票据按本人试用设备的报价显示（入口或本机记住的是别款时先收起），底部按钮为灰色无金额的「抵扣购机」，失败时按钮上方写「设备信息加载失败，正在重试」并自动重读；本机记得这次试用的清单里有其他设备时选择区用静止占位行，不记得时先不显示，读到有其他设备再出现；已有清单的刷新保留原内容。结算页报价未读到时金额为骨架或「—」，不能支付，不显示原价。
- 异常2：Given 某一款不可买（缺货、名额用完、不具备购买资格）或报价读取失败 When 显示 Then 只有那一行不可选并写原因，资格原因带「查看购买条件 ›」；其余照常。全部不可买时底部为灰色无金额的「抵扣购机」，按钮上方写「暂无可购买的设备，试用照常进行」，可抵扣期写「暂无可购买的设备，试用收益仍保留」；清单只有 A 时写 A 自己的原因。
- 异常3：Given 已选设备被下架、移出清单或变为不可买 When 回到前台、进入结算或提交时重新读取 Then 提示「该设备已不可选，请重新选择」并清空选择（票据收起，底部为灰色「请选择设备」），不替用户换货；只剩 A 时也保留这一行让用户点选。
- 异常4：Given 提交被明确拒绝（价格或优惠变化、下架或移出、售罄、名额、资格、余额不足、暂时无法购买） When 回执到达 Then 按原因给出去处：价格变化写新价划旧价并要求再点一次（只是累计抵扣增加使应付变低时直接继续）；余额不足写差额与「去充值」，充值后回到同一设备的试用结算；其余提示原因并可重选；本次提交释放。
- 异常5：Given 已有进行中的原购买（A 的外部付款待支付，或余额付款结果未知） When 打开试用详情 Then 选择区上方单独一张「进行中的付款」卡，设备、方式、金额、状态取自这笔付款；清单锁定、不显示票据；按钮为「继续支付」或「查看进度」；设备页试用行「取消试用」位置写「付款中，不能取消试用」。原提交查询返回可用原提交号继续（没有送达，或已受理但没有结果）时，按钮为「继续支付」，用原提交号和原商品、金额、版本，由用户重新输入支付密码后继续，不自动重扣；不能续付时只读查询。权威终态（试用结束、别处已成交）优先于本机未送达的提交。
- 异常6：Given 原外部付款的查询结果为未付已终结，或迟付且确认宽限已过（服务端给出，客户端不用本机时间推断） When 打开试用详情 Then 不再算进行中的原购买，试用仍可转购时可以重新选设备购买。When 用户从原付款单进入 Then 沿用现有迟付款的说法：这笔付款晚于截止时间，不会交付，款项会原路退回；不出现「复核」一类的内部说法；给出回到试用详情重新选择的去处。

**③ 数据字典+生成规则**

| 字段 | 类型 | 生成规则/约束 |
|---|---|---|
| claimNo/serverTime/options | string/ISO 8601/array | 可购设备接口返回；A 始终在首行；B 下架或被拦时不返回，售罄返回但不可买 |
| productNo/name/imageUrl/productType/inventoryMode | string/enum | 服务端商品快照；A 下架后仍有名称、图、售价 |
| originalTrialProduct/paymentMethods | bool/array | 是否 A；付款方式由服务端给，B 只有 WALLET |
| priceUsdt/storePriceUsdt | decimal string | A 为领取时锁定价，另给商城现价 storePriceUsdt（不同时标「领取时价格」）；B 为商城现价 |
| canPurchase/unavailableReason | bool/code | 服务端判定；客户端按原因码归类到商城已有文案，不自行推断能否购买，不显示原始码 |
| quote.amountUsdt 等 | decimal string（六位） | 显示取两位；是否为 0、余额是否够用按六位判断 |
| quoteVersion | string | 确认版本，转购与外部付款取报价必须回传；单价或优惠变化时变化 |
| originalPurchase | object/null | 进行中的原购买：kind 为 BALANCE（commandKey）或 EXTERNAL（intentNo），带设备、付款方式、确认金额、状态 |
| purchasedDevice | object/null | 已转购时所买设备 |
| canResumeSameKey | bool | 原余额提交能否按原提交号重新验密继续 |
| trialPurchaseOutcome | enum | 原外部付款的终结结果：UNPAID_TERMINAL、LATE_PAYMENT_REVIEW；没有时按仍在进行处理 |
| 预选设备 | 本地 | 按账号＋领取单记住，只用于回到试用详情时预选；同一行记住清单里有没有其他设备 |

**④ 状态机+禁止动作**
沿 FEAT-TRIAL03 的生命周期。选择区状态：未支持（404）→ 单设备旧流程；读取中 → 就绪／失败（自动重读）；就绪下选中、未选（等待重选）、全部不可买；有进行中的原购买时锁定。提交：提交中 → 成交／明确被拒（释放）／结果未知（只按原提交号查询）／未送达可续付（用户验密后续付）。禁止：客户端推算金额；读取失败当作下架或应付 0；提交后自动换成别的设备；结果未知期间对别的设备发起转购；从活动或代金券入口用试用抵扣金。

**⑤ 多状态覆盖**
默认（多款、A 选中）、选中 B、选中 Cloud Share（应付可能很低或为 0）、可抵扣期（无立减标题，票据首行写设备名）、领取价与现价不同、单项不可买、单项报价失败、清单读取中与持续失败、全部不可买、所选失效、进行中的付款四种、结算报价读取中与失败、余额不足与不足 0.01、价格变化与仅优惠变化、应付为 0、充值返回、后端未支持。极限态：长设备名、360 宽、9 种语言、明暗主题。

**⑥ 点击流矩阵**

| 触发 | 目标 | 反馈 |
|---|---|---|
| 首页、设备页、赚取页试用入口 | /pages/me/trial | 不变 |
| 选择区单选行 | 原地选中 | 票据与按钮同步该款报价 |
| 「查看购买条件 ›」 | 商品详情 | 只在详情可达时出现 |
| 「抵扣购机 · 应付」 | /pages/store/checkout?source=trial&product=<编号> | 进入该款的试用结算 |
| 结算「更换设备 ›」 | 试用详情选择区 | 保留当前选择 |
| 结算「去充值」 | 充值页（带返回目标） | 到账后「返回继续支付」回同一设备的试用结算并重新核对 |
| 商品卡（带标签） | 商品详情 | 详情里有抵扣入口 |
| 详情「用试用抵扣金购买」 | /pages/me/trial?product=<编号> | 进入试用详情并预选该款 |
| 详情「立即购买」 | 普通结算 | 原价，不结束试用（机位满时入仓库，现规则） |
| 「继续支付」／「查看进度」 | 原付款 | 按原身份恢复 |
