# 手机任务运行合同

> **H5 Lite 说明**：本文为 App 与服务端规则。H5 Lite 不展示手机设备和手机任务，也不读取手机运行状态；账号资金记录中的手机收益照常完整展示。

手机与 IDC 任务由服务端按冻结的任务时长和收益处理。Android、iOS 不下载模型、不创建计算 Worker、不执行推理、不上传模型结果。手机的安装绑定、登录会话和激活权限继续沿用既有业务入口；H5 只读，不获得手机在线确认权限。

- 打开 App 或回到前台时立即确认本机在线，持续前台期间每 300 秒确认一次。在线有效期由服务端接收时间决定，最多继续 3600 秒；本地时间与页面进度不能续期。
- 首页、收益和设备详情共用账号级任务快照、在途请求及 60 秒刷新节奏；离开这些页面停止自动读取。切换页面和手动刷新遵守同一冷却。
- 任务进度由服务端时间快照和单调经过时间推进；到达预计完成时间仅显示收益确认中，余额与凭证等待服务端结果。
- 锁屏、进入后台或 App 被系统结束，不发送离线停算请求。有效期内服务端继续处理；未续期到期时未完成任务作废，恢复后按新区间开始。IDC 不依赖手机有效期。
- 凭证沿用现有入口。新任务只展示任务、设备、起止时间和入账结果，不展示不存在的模型产物或验真字段；旧真实执行凭证保持可查。

专属模型下载配置、ORT 依赖、资源准备脚本与真实计算 API/Worker 入口已移除。其他业务的本机设备信息采集和 Nova 能力不在本次删除范围。

生产构建与类型检查属于源码验证。Android/iOS 后台与恢复、服务端到期、过期重连、IDC 独立结算及旧新凭证仍须通过实际业务 E2E 验收，不能据本文件宣称已完成。
