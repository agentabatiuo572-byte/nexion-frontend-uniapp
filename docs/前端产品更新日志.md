### 🆕 账号/设备检测(单点登录 + 任务中断回退 + 新设备重新校准) + 手机实时算力显示

**概述**：新增两块强相关能力。① **账号/设备检测**：账号同一时间只能在一台设备运行挖矿——他端登录立即接管,旧端被踢到阻断屏、进行中任务立即作废回退(无宽限、不发回执)、挖矿冻结;退出登录同理;**新设备**登录触发重新校准算力仪式。② **手机算力显示规则**：手机「算力」虽是仿真数字,但**基线确定性派生自真实设备信号**(机型/RAM/核数/GPU,`uni.getSystemInfo`+`navigator.*`+WebGL),失败取低、按 deviceId 缓存——保证**排序永不翻车**(低配机数学上不可能显示高于高配)、可复现、防多端薅羊毛。手机卡片显示三层:稳定**算力上限**(TOPS·Tier,可比身份数)+ **实时有效算力**(=上限×状态因子≤1×抖动,永不超上限)+ 曲线 + 正向因子标签(满速/稳定加成提升中/节能模式…)。单点登录按 **deviceId** 而非 sessionId 判定(同机多 tab 不误踢,异机才踢)。
