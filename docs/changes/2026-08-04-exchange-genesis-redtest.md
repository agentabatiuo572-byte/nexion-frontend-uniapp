### 🔴 R2 第一轮把我自己的哨兵测红了 —— 判据被就地改强

首轮 R2 注入后,`A② 首个 await 之后 0 处裸读活值` **没红**。原因是我把豁免写成了「这一行里
只要出现 `snap.` 就整行放过」,而注入后的那行是

```js
const succ = snap.direction === "usdt2nex" ? app.debitBalance(snap.fromAmount) : app.debitNex(fromAmount.value);
```

—— 同一行里既有快照又有活值,靠 `snap.direction` 就把活值一起赦免了。**混着写的那一行恰恰是
最危险的形态**,却正好从这道门底下走过去。改法:把「确认后复验」两个**准许的表达式**先从行里
抠掉,剩下任何活值一律违例;顺手把 `rate.value` 也纳入扫描口径(它只允许出现在复验那一处)。
改完 R2 稳定红 6 条。
