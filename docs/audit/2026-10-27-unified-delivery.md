# R20、试用流程及紧凑重试提示统一交付

日期：2026-10-27。此报告覆盖本轮新增及合并范围；历史阶段报告保留原始分数与失败记录。

## 实施结果

- R20 收益卡恢复批准原图的光晕、轨道和底座反射，按钮保留细边玻璃质感。统一实景复审发现 320px 中文手机说明孤字（8.8 分），已将说明精简为「连接 Android 手机」，最终增量复审见下表。
- 试用领取增加确认、激活中、成功和可重试反馈。领取后福利卡保留，展示试用中、抵扣保留、结束、已转购等状态；首页、赚取和设备管理显示独立试用设备及占位。提前购买继续使用既有原子转购和当前实际抵扣，不将预计收益提前记账。功能规则已同步到主 PRD 和试用 PRD/报告。
- 正式客服清空接口按账号及客服持久记录用户可见边界，用户历史、详情、附件及恢复命令服从边界，客服后台完整记录保留。补充精确拒绝、未知结果原命令恢复、客服更换、存活页面草稿/失败气泡及迟到回调的处理。功能规则见 [客服 PRD](../../PRD/UVEL_客服会话连续性与用户侧清空_20261027.md)。
- 紧凑读取错误/降级提示采用左侧可换行说明、右侧独立操作槽，至少 44px 触控。赚取、首页、活动、设备、团队、消息、偏好、信任中心及下一课程提示逐处接入；完整 EmptyState 和发送/交易重试继续使用所属交互。
- 同类文字重试使用「重试 / Retry / Thử lại」，统一为项目正文字体、600 字重、13px 字号、20px 行高。去除收益页旧「请重试」、流水按钮等宽字体及零散字号；扩展检查试用、网络、质押、课程、订单、充值读取、邀请/海报、等级规则及恢复页面的标签。只对读取恢复操作应用字体，不改交易确认或消息重发的语义。源码审查发现搜索部分来源失败遗漏（8.8 分），修复后独立复核 9.2 分。
- 商城窄屏恢复标题精简为「信息暂不可用」，同时对长标题平衡换行；订单读取恢复命中区由 32px 补到至少 44px。底部 Liquid Glass、已有业务点击/键盘/禁用逻辑保持。新增重试排版属于视觉变更，记录于前端更新日志，不新增交易或收益规则。

1. 正式 TEST 部署、真实 JWT/HTTP/WS、对象存储、真实账号重新登录/物理换机、原生安装与软键盘/硬件心跳尚未验收；本地浏览器模拟与资源编译不等于线上生效。后端清空迁移必须先于接口启用。
