# API 域名环境

TEST构建使用npm run build:h5:test（Vite --mode test），读取.env.test的https://api-test.uvel.ai；PROD构建使用npm run build:h5:prod，读取.env.production的https://api.uvel.ai。本机开发保留现有开发代理。CI不得再以旧IP覆盖base URL。

本次仅调整等价API接口地址和构建环境，不改界面、业务规则或权限。TEST H5通过https://api-test.uvel.ai/app/访问，与API同站以维持既有刷新Cookie；不把IP页面跨站Cookie问题伪装成已验收。实际验收和部署回执见PC仓库docs/PRD/TEST-PROD接口域名隔离-20261115.md。

生产域名配置在test分支准备，不表示已合并main或发布生产。每批生产合并/推送仍需用户明确批准。
