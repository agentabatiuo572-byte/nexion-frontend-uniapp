# 展示数据分层缓存

日期：2026-11-02；2026-11-16 修订首屏预取与本机只读快照。适用于正式 App/H5，补充并调整《五 Tab 快切保护》。缓存只减少展示读取，不提供操作资格。

## 数据与有效期

| 数据 | 保存方式 | 更新规则 |
|---|---|---|
| 团队文字邀请码 | 按账号、API 环境和地址持久保存 | 首次服务端确认后复用；后续正常响应确认变化才替换；不因奖励加载或失败清空 |
| FAQ、课程列表与内容 | 内存 5 分钟，按账号/会话、语言、分页或课程 ID 隔离，跟踪服务端内容版本 | 服务端发布版本保留在结果中；新读取确认版本变化使相关旧结果失效；重试/手动刷新强制读 |
| 首页收益、设备、奖励、支付设置摘要等动态展示 | 成功结果内存 5 秒；四个 Tab 的首屏数字另按账号、API 环境和地址、语言、非秘会话链保存本机只读投影 | 成功后计时；短时返回复用。重启后确认同账号、同会话归属才恢复首屏只读数字并后台真实读取；快照不提供操作资格，设备运行态与完整目录不持久恢复 |
| 任务配置、头像 | 内存 60 秒 | 配置的全部必要请求成功才算成功；头像须真实读取成功，合法空头像也算成功；服务端修改回执更新展示 |
| 已有行情、任务分配 | 保留既有 30 秒、60 秒规则 | 手动刷新及操作后的权威回读继续走各自强制入口 |

五 Tab 既有 1 秒内 3 次变化、3 秒快切保护保留；只对默认 5 秒动态展示延长复用，内容及 60 秒数据不因保护超过其有效期。没有后台定时刷新；有效期结束本身不触发请求。同对象在途读取共用。普通失败只在同一次访问内合并 1 秒，不作为成功缓存；HTTP 429 继续遵守 Retry-After，手动刷新不绕过服务端限流。

## 展示与刷新

- 主页面、分享海报等只读消费者通过 Store 的 ensure/read 入口读取配置、头像、首页、设备、收益释放摘要、支付设置摘要和已发布内容。多个消费者使用同一份读取结果。
- 首页待办等纯展示响应不会因无关业务写入被永久留在初始骨架；账号、会话和可见页面隔离继续生效，待办入口不作为操作资格。
- 同账号、同服务已有有效内容（含已确认恢复的首屏只读快照）在后台更新期间保持可见，更新成功后整体替换，不显示额外刷新文字。首次无快照仍显示正常骨架或「—」，不补假零；权威成功的零正常显示，首屏金额直接显示目标值。网络/临时服务失败可保留已确认展示，但不能当作新请求成功；认证、权限和协议失效按现有业务撤销展示。
- 切换账号、会话归属、服务时隔离结果并丢弃迟到响应。语言变化不会复用另一语言的内容。普通页面刷新只处理当前可见页。每进程、每个已确认账号作用域仅一次：在首页可见、首页首屏必要读取已 settled 且目录 barrier 完成、前台许可后，分两批空闲预取其它 Tab 的首屏展示；不挂载隐藏页，不发页面访问观测。离开首页、隐藏、离线或作用域变化停发后续批次，恢复许可只续本次。相同资源共用在途读取并遵守 429 期限。
- 下拉刷新、显式重试均绕过展示有效期。FAQ/课程的手动刷新清理对应内容窗口，动态展示刷新使窗口失效并重新执行当前页读取。

## 实时操作边界

支付、提现、领取、设备操作、购买及执行前的资格查询，仍调用实时 API。已核实的置换资格/报价（含 `/api/app/trade-in/capacity-quote`）、订单试算（`/api/orders/quote`）、提现资格（`/api/withdrawals/eligibility`）及客服连接票据 POST 属于实时读取，不按业务写入清掉其他展示缓存或推进被动读取的业务写版本；真实业务写入继续使动态展示失效。支付设置摘要只包含展示字段，与弹层中的操作状态分开，不能提供 credentialVersion 或支付授权。

课程内容 GET 可复用，但每次开始学习仍实时执行 start 并核对课程 ID/版本；成功回执更新详情并使目录进度重新读取。答题、完成、回执查询、异常恢复和权威回读不缓存。答题/完成后清理列表和详情展示，包括结果未确认的失败场景，避免旧奖励或旧进度被当作新结果。

## 发布版本边界

本轮不增加后台版本探测接口。运营发布后的内容在真实读取发现新课程版本、手动刷新或 5 分钟后下一次读取时更新；不承诺发布瞬间推送。商品目录的运行版本变化不会使无关 FAQ/课程内容失效，操作仍受各自实时版本校验约束。内存请求窗口随 App 进程重启消失；邀请码及首屏只读投影按上述归属规则持久恢复。已完成同作用域预取或有有效本机快照时，会话确认后第一次进入四个 Tab 的首个内容帧有首屏数字。预取未完成、无快照时只消除没有依赖的串行，保留会话恢复、目录 publication barrier、团队成员游标分页和 429 等真实依赖；不承诺任意慢网或失败下都一轮。


## 首屏本机快照边界（2026-11-16）

- 仅保存 Earn 各 period 收益及最近一条结算、Store 券票数字和活动入口小 DTO/收益比较数值、Team 收入/人数/rank 进度/邀请奖励、Me 钱包/收益及释放桶/行情价。共享来源只写一次；每块记录源生成时间（源未提供则为空）及接收时间，整行共用账号、环境、地址、语言、非秘会话上下文；不存身份副本、token、设备运行态、完整目录或活动规则。
- 当前 live 成功（含零、空、disabled、null）优先；允许的同作用域快照只作显示回退；否则未知。合计任一来源未知则「—」。不恢复 app.user、设备、佣金事件、release 权威、PRODUCTS、remoteReady、hasSnapshot 或目录 displayProof。支付、提现、领取、购买、券领取仍走实时资格/报价与原操作流程。
- 启动 restore 成功并核对 vault/auth/app 的账号和会话链、完成绑定后才以 resume 理由恢复；确认前页面和读屏均无快照私有金额。启动候选变为确认会话的 continuation=false 及 prepareProductCatalog 初始化不删盘。退出、失效退出、交互式登录（包括同号重新登录）、已接受会话换属删旧行；正常 token refresh continuation 保留。语言或环境/地址变化丢整行。
- 真实运行时/目录展示凭据失效、成功业务写入撤受影响块并拒绝迟到写回；普通目录重读及网络/5xx/429 暂时失败保留允许的旧显示。认证、权限、协议、配置和业务严格拒绝撤销对应块；活动共享缓存与已挂载入口使用相同分类，成功空列表替换旧活动。活动详情/规则不从磁盘恢复，打开原规则弹层前读取当前详情。
- Today/Week/Month 按源 generatedAt 与 business-calendar 对应轨道判断业务期间，越界的整个 period 未知，累计可保留；不把过期 period 改成 API 的三 null 成功空，不用设备时间补源时间。券与活动按有效期过滤。快照同样遵守隐私遮罩「••••」及读屏遮罩。
