# H5 Lite 前台读取与会话续期

## 范围与来源

- 从 `origin/h5-lite` 的 `aca365949e75e538a4910c9a01f8233511b2d038` 准备隔离候选，移植 App 已批准的 `b2d013a9`、`d81dcc18` 同范围优化。
- 此前正式 H5 独立产品线为 `h5-lite-main` 的 `8ed7aabb3316`，不能以 App main 已包含优化代替 H5 已发布的证明。
- 保留 Lite 现有页面裁剪、只读手机能力、退休路由、官方链接锚点、语言列表和失败恢复，不新增页面、布局、文案或资金操作。

## 页面读取

| Lite 页面/场景 | 读取时机 |
| --- | --- |
| 首页、收益、我的、设备、试用 | 进入及相关操作读取权威状态；试用倒计时到本地确认的服务端期限时重新核对，不自行认定服务端已完成状态转换 |
| 钱包余额入口、提现、账单 | 进入及相关操作读取；移除全局每5秒扫描提现订单的请求 |
| 打开的在途提现详情 | 仅当前详情可见且前台在线时每30秒读取该单；终态、离开、后台、离线、退出或换账号停止 |
| 通知与消息抽屉 | 打开即读；移除全局后台周期扫描，保留既有实时消息与失败恢复 |
| 前台空闲兜底 | 账号散列分配30分钟周期中的时点；每轮仅检查当前页对应的一项资源，后台、离线或账号未就绪时停止 |

进入读取沿用 Lite 现有被动读合并、当前账号及请求代次保护；失败仍使用原反馈和恢复路径。下拉刷新继续等待当前页及失败区块，配置使用显式刷新入口。

## 配置与会话

- 平台配置改读带版本的 snapshot，一个响应同时包含平台与推荐配置；已知版本未变化时复用已确认内容。旧服务端返回有效旧格式时保留兼容读取。
- snapshot 保留 `officialLinkFragments=true`，避免丢失 Lite 正式官方链接的锚点；继续保留 `networkPulse`、`interfaceLanguages`、公开统计来源核验及环境漂移失效保护。
- 公共配置按账号错峰每30分钟检查；实时配置失效事件在90秒窗口内错峰重读；失败按既有失败展示并在60秒后自动重试。显式下拉刷新不受自动重试时点阻断，请求合并与既有429冷却仍生效；退出前台或离线暂停自动读取。
- 取消前台每分钟无条件刷新会话，按 JWT 到期提示错峰续签；回到前台向服务端校验。JWT 仅用于调度，不代替服务端权限、撤销及过期判定。
- H5 Cookie、多标签页锁、同刷新链校验、请求 revision 以及退出/换账号隔离保持。收到新的同链访问凭据后，支持 reauth 的 WS 原连接重新鉴权，保留 watch 和在途可靠消息；不支持或失败时沿用重连与权威读回。
- WS 心跳15秒、pong超时45秒、连接未就绪的5秒补读保持原值，不扩大 H5 的手机任务执行权限。
- H5 离线或页面不可见时停止既有实时连接及其5秒补读，路由守卫在此期间不能重新启动；恢复前台在线后沿既有账号守卫恢复。

Lite 既有业务日历保留10分钟独立节流路径，仅补前台在线门控。其他依赖页面的空闲日历降频增量已撤回，未应用方案由主任务单列确认后再处理。

## 验证边界

本批仅本地类型/静态检查及 H5、APP 资源构建；不运行单元或集成测试，不在 TEST 压测，不提交或发布正式分支。正式页面、协议、长时间前后台/离线/会话轮换与权限恢复由主任务在已授权正式入口验收；本地构建不能代替实景通过。

本地 `.env.production` 默认读取浏览器同源；本批正式目标资源构建显式设置 `VITE_NEXGRID_API_BASE_URL=https://35.77.108.238`，不将当前指向 TEST 的 `api.uvel.ai` 当作正式验收入口。
