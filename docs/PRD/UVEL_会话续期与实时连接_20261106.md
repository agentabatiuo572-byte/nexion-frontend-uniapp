# UVEL App 与 H5 会话续期与实时连接

适用于原生 App 和同仓 H5。已登录用户在前台在线时，客户端按当前访问令牌的到期时间安排续期。常规令牌从到期前 30 秒起向前分布在 30 分钟内，按账号和客户端实例错峰。短有效期令牌按签发时长缩小窗口。后台挂起、计时器延迟或断网后恢复时，重新按当前时间判断。H5 继续使用 HttpOnly Cookie 和同源标签页的续期协调，原生 App 继续使用加密保存的刷新凭证。

回到前台、网络恢复或实时连接收到鉴权拒绝时，客户端通过已认证接口核实会话。进入续期窗口时可由续期接口直接确认。已过期的普通 API 请求沿用现有 401 恢复流程。H5 标签页挂起期间若错过同一会话的更新，可在恢复时用共享 Cookie 补齐。服务端确认注销、吊销或登录被替换时，客户端停止旧会话的实时连接并执行现有登录恢复流程。暂时的网络故障允许重试。

访问令牌更新后，支持换证的就绪 WS 使用新访问令牌获取一次性票据，在当前连接发送 `reauth`。收到 `reauth-ready` 后继续监听当前会话，未完成的消息回执继续由原连接接收。旧服务端、连接已断开、换证被拒绝或超时时，由既有重连和消息补齐流程恢复。主动退出或账号切换时关闭旧连接，旧连接的事件和回执不能写入新账号。

验收覆盖 App 和 H5 登录、前台空闲跨过一分钟、临近到期实际续期、同一 WS 换证及继续收发消息、旧服务端和断网重连、前后台切换、会话吊销、同端替换登录与切换账号。H5 另验收两个标签页对共享刷新 Cookie 的协调。以接口时序、WS 连接数及用户可观察结果核对。
