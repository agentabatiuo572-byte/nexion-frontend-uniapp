# UVEL App 前台数据刷新

适用于原生 App 和同仓 H5。每个前台在线账号按稳定的账号偏移量分散在 30 分钟内执行空闲刷新。每次最多发送一个当前页面需要的业务读请求。退后台、断网或退出登录时停止自动读取，恢复后按当前页面和有效会话读取，切换账号后丢弃上一会话的状态。

| 页面 | 刷新时点 |
|---|---|
| 首页、赚取、我的、设备、试用 | 进入后读取试用状态，领取后使用服务端结果。倒计时依据服务端时间在本地更新，到达试用或宽限期结束时间后读取一次服务端状态。停留页面时纳入 30 分钟错峰刷新。 |
| 结算 | 进入普通结算时读取试用状态，继续在下单时校验当前资格和报价。 |
| 钱包及提现列表 | 进入页面或执行相关操作后更新列表。 |
| 银行或加密货币提现详情 | 打开时读取当前单据。单据在途且页面可见、在线、已登录时每 30 秒刷新本单，到达终态或离开时停止。 |
| 钱包账单 | 进入时读取。空闲刷新仅更新当前筛选的首页，指定收据继续通过进入时的查找流程定位。 |
| 消息和通知 | 打开后立即读取，通知页停留时纳入错峰刷新。入口关闭期间红点可能晚于其他设备上的变化。 |

在 10 万前台账号均停留于有空闲刷新的页面时，这项空闲刷新平均约每秒 56 次。主动操作、在途单详情、会话维护及实时连接分别计量。

试用终态以服务端确认为准。宽限截止时若服务端的周期结算尚未完成，页面暂时保留上一次确认的状态，后续进入页面或按页面刷新策略读取时更新。

验收记录当前页面和账号的接口请求，覆盖试用领取与到期、钱包和账单进入、两种在途单详情、消息打开、回前台、断网恢复、退出和切账号。检查离开详情后停止定时读取，以及空闲刷新只读取当前页面的一项资源。
