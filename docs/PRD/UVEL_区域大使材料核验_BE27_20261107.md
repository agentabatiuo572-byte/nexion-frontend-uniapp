# 区域大使申请材料与独立核验

2026-11-07。原 47 项 BE-27；本轮用户已确认 App 与 H5 Lite 原区域大使申请页的材料与进度范围。本文记录产品行为；真实 TEST、浏览器与原生设备验收由本次执行记录给出，编译通过不代表实景通过。

## 入口与材料

团队 → 区域大使 → 我的申请。在每份本人原申请内展开「申请材料与核验进度」，读取该申请编号的材料，不新增全局导航。显示材料版本、缺项、业务核验与费用核验各自的状态、审核人、时间和理由；费用核验另显示认可金额，线下业务核验另显示核实有效人数。金额与人数遵循页面的数据隐藏设置。

必需材料以服务端 `requirements` 为准：线下场地为活动签到／活动证明／费用凭证；达人推广为推广内容／流量／费用；印制物料为清单／配额／费用；开发支持为需求／工时／验收／费用。每项可上传多份文件，提交时必须填写不超过 4000 字符的材料来源说明。缺项展示服务端结论，选择或上传成功本身不表示材料版本已提交或核验通过。

App 原生复用现有相册／相机 `uni.chooseImage`，选择 PNG/JPEG；当前安装的原生运行库没有 `uni.chooseFile` 实现，不承诺原生选择 PDF。App H5 与 H5 Lite 复用 H5 `uni.chooseFile`，支持 PNG/JPEG/PDF。页面按平台提示真实范围；每份不超过 10 MiB，每版最多 12 份有效附件，服务端继续校验实际内容。图片通过鉴权私有下载后预览；PDF 在 H5 下载，原生已有 PDF 可用系统文档查看器打开。

取消系统选择不创建材料版本。上传可取消，失败可沿原上传键重试；尚未提交附件可移除。只有点击「提交本版材料」才以 `expectedMaterialRevision` 和 `Idempotency-Key` 提交新的材料版本。提交失败保留草稿供同键重试；刷新有未提交修改时，先明确提示将放弃本地修改。账号或环境切换清除组件内材料、草稿和预览，并中止本组件上传／私有文件读取，迟到响应不得进入新账号页面。

2026-11-08 同范围修复：从系统相册／相机返回时，申请历史会重新读取；同一账号、绑定代次、鉴权状态、环境和申请编号未变，仅申请对象被新响应替换，不应折叠材料面板或重置正在进行的文件选择／上传。取消选择保留原展开状态和已有材料，确认有效图片后继续原上传流程。上述归属字段实际变化时仍清除草稿、取消请求，原迟到响应校验保留；不改变父页面生命周期或材料版本提交规则。

## 核验与金额

可以事前申请。最终批准必须材料齐全、活动或服务实际完成、同版业务与费用核验均通过且财务认可金额不低于申请额；本页只展示进度与阻断原因，不代替管理端核验或批准。线上预期人数与日常签到不能充当线下实际有效人数，原有线下至少 100 人规则保留。

补交或替换材料生成新版本，两项旧核验结论不沿用。只有本人未批准且退回补材料的原申请显示下调申请额输入，下调须大于 0 且不高于当前申请额；不自动把申请额改成财务认可额，不更换原申请编号，新版重新核验。历史待审申请缺类别时由本人明确选择原类别，再按材料包的 `requirementsByBucket` 对应分类要求补齐，首版同时提交类别与附件；不得使用猜测的默认类别或空附件先保存类别。已选附件时先移除或取消草稿再换类别，避免隐藏不属于新类别的附件。新申请只批准所选支持类别的额度，客户端不承诺同时开放其他类别。

历史已批准申请显示保留说明，不补造材料核验结果，也不调整旧额度；已批准／已拒绝或服务端禁止提交的申请只读。核验人与最终批准管理员分离，以及权限、预算覆盖率、版本与金额约束均由服务端执行；本页按独立核验结果与阻断码的本地化含义展示，未知阻断不向普通用户暴露实现码。

待审批和补齐引导仅用于仍为 `PENDING` 的申请：已批准／已拒绝终态不再显示待最终批准、缺项补齐或批准阻断提示，保留材料版本、附件、来源说明及两项核验事实明细。只刷新材料进度时，即使申请列表状态尚未同步，材料包返回 `APPLICATION_NOT_PENDING` 也按终态抑制上述引导；其他业务阻断仍保留待审批引导。两项核验均 `PASSED` 时，不再显示“仍需独立核验”；未终态且确有批准阻断时，仍展示对应原因。此修正仅调整原材料区条件，不改变资格门槛、核验结果或终态只读规则。

## 接口与语言

使用 `/api/app/team/ambassador-applications/{id}/materials` 的 GET/POST，附件上传 `/materials/files`，私有读取 `/materials/files/{fileId}`。上传返回附件对象，GET/POST 返回材料包；`fileId` 是不透明字符串。复用现有 ApiClient 鉴权、续期、会话归属检查与取消能力，不引入上传框架。

新增文案覆盖已上线九种界面语言：中文、英文、越南语、印尼语、马来语、菲律宾语、俄语、哈萨克语、乌兹别克语。
