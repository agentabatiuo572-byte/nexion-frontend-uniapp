## 试用导入与局部别名（BUG-366）

原始状态消费由 TypeScript 词法绑定识别，不再由 `freeTrial` 这个局部名字决定。仅对命名 free-trial 模块的依赖面及原定义面使用现有 TypeScript / Vue 解析器；相关源解析失败时直接失败，不降级为文本匹配或成功。

- 按真实模块目标核对 `@/store/free-trial` 和指向同一文件的相对路径（含显式 `.ts` / `.js`），识别命名导入、导入别名及命名空间导入。命名空间的局部声明别名、静态 useFreeTrial 属性及 `const { useFreeTrial: getTrial } = trialStore` 工厂解构继续按同一初始化链追踪；其他同名函数或对象不算试用消费。
- 追踪调用结果和局部声明的初始化别名链，包括 `const trial = useFreeTrial()`、`const st = freeTrial`、直接调用后的 `.status`，以及静态字符串 `['status']`。`const { status: state } = useTrial()` / `const { status } = trial` 在解构发生点计作原始读取；普通函数参数、块级变量和模板 `v-for` / `v-slot` 的遮蔽按各自绑定处理。
- Vue 模板插值、指令表达式、动态参数和事件表达式参与同一发现过程，定位回原始行。发现不求解跨函数返回、后续赋值、动态反射或任意数据流；出现这些新消费形态需另行建立判据，不扩大现有权威用途证明。
- BUG-154 两种完整有限证明、关键导入、canonical 匹配、作用域和支付保护均保持；只扣除原来已证明的读取节点。同文件／同行额外的原始读取仍单独报红。ALLOWLIST、六个 MONEY_PATHS、两个定义面以及零命中失败规则均未增加豁免。
