# 消息中心交互约定

设计参考：[主界面 V3](design/message-center-20261002-v3.png)、[滚动状态](design/message-center-20261002-scroll.png)。图中示例记录和数字不构成业务事实，通知与服务数据必须严格分区；滚动状态图中混入的服务示例不予还原。

- 配色遵循 nexion-design 与项目现有 tokens：深色黑底、荧光绿少量强调；浅色暖白底、蓝色强调。所有交互按钮复用 Liquid Glass，内容行保持扁平。
- 到达页面顶部时显示标题、总未读、通知/服务一级分区及当前分区末级筛选。
- 明显向上滑动浏览后收起大标题和一级分区，末级筛选保留在顶部；紧凑标题保留当前分区上下文。
- 明显向下回滑恢复一级分区，不要求先回到列表顶部；回到顶部再恢复大标题。切分区时重置相应导航状态，不复用另一分区过期滚动位置。
- 轻微手指抖动不反复展开收起；滚动位置不能因动画来回跳。键盘聚焦的一级控件不在操作中被收起。减少动画设置下取消过渡，但保持功能相同。
- 所有铃铛和 Me 消息入口直接进入全屏消息中心，无侧边抽屉或遮罩；保留当前分区，入口可指定初始分区。在中心再次点铃铛不叠加页面，返回恢复来源页面；冷启动进入时返回 Me。分区切换/查看总览不标记人工或工单已读，通知设置保留在全屏页内。

- 人工浮标与客服渠道的“在线会话”统一进入服务分区；点会话行进入现有全屏聊天，返回保留服务分区。“会话管理”仍可新建会话和管理历史，不作为独立人工快捷入口。

验收：顶部→向上浏览→继续阅读→明显回滑→切换服务→打开会话/工单→返回→刷新；覆盖短列表、长列表、空列表、加载失败、320px、中/英/越、浅/深主题和键盘。
